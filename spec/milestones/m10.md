### 1. Client metadata (M10) — `edge_core::client`

`ClientMetadata` holds `provider: EdgeProvider` (Cloudflare/Fastly/Mock),
`client_ip`, `pop`, `original_header_names`, `geo`, `network`, `tls` — all
fields `Option`, all `Serialize` (the P7 handler reports the snapshot as JSON).

Sources (decision D23):

| Common field | Cloudflare | Fastly |
|---|---|---|
| client IP | `cf-connecting-ip` request header | `Request::get_client_ip_addr()` |
| POP | `request.cf.colo()` | `compute_runtime::pop()` (FASTLY_POP; Viceroy → `XXX`) |
| original header names | not exposed → `None` (P8) | `Request::get_original_header_names()` |
| geo | `request.cf` (country/continent/regionCode/city/postalCode/metroCode/lat/long) | `geo::geo_lookup(client_ip)` |
| ASN/organization | `request.cf` asn/asOrganization | geo `as_number`/`as_name` |
| proxy | not exposed → `None` | geo `proxy_type`/`proxy_description` |
| TLS protocol/cipher | `request.cf` tlsVersion/tlsCipher | not exposed by fastly 0.13 → `None` |
| JA3/JA4 | not exposed → `None` | `get_tls_ja3_md5()` (hex) / `get_tls_ja4()` |

Sentinel → `None` mapping on Fastly: `"--"` POP, empty strings, `0` ASN,
`0.0`/`0.0` coordinates, `??` continents, `Unknown` proxy enums.

The metadata lives in `Context` (constructed via
`Context::from_platform_with_metadata`), so `Context::client()` returns a
reference to an immutable snapshot that is clone-safe for deferred work (M9).

### 2. Structured log fields (M11) — `edge_core::log`

`LogFieldMap` (shared by all three platforms) implements the §6 contract:
- Keys: normalized lowercase, validated `[a-z0-9][a-z0-9._-]*` (invalid →
  `Error::LogField`); empty values omitted; set replaces.
- Per-value budget 1024 B (char-boundary truncation); aggregate budget 4096 B
  of `key.len()+value.len()` — oldest dropped, newest retained (deterministic
  P11: 20×303 B → the 13 newest `f07..=f19` survive).
- Truncation/eviction emit diagnostics through the log sink (`Warn`).
- `serialize()` → JSON object with sorted keys (deterministic).

Adapter finalization (`Platform::finalize_log_fields`, runs for every
outcome — success, synthetic error, timeout, catch-all):
- **Fastly** (`serve`): emits one record `{"fields": {...}}` to the configured
  log endpoint (stderr fallback) and returns `None`; `response_to_client`
  strips any origin-supplied control header (P10) so nothing reaches the client.
- **Cloudflare** (`serve_fetch`): returns the serialized control value;
  `convert::apply_control_header` strips an origin-supplied
  `x-edge-log-fields` (diagnostic) and inserts the facade's value — both on
  the success response and on `error_to_response` catch-alls (P9).
- **Mock**: snapshots the map into `Records::log_fields`/`finalized_log_fields`
  and returns the serialized value; `strip_control_header` is available for
  native tests simulating the boundary.

### 4. Notes & decisions recorded

- D22 (log-field control header + shared budget policy) and D23 (client
  metadata source mapping) are recorded in SPEC.md §13.
- The workerd harness needed `http = (cfBlobHeader = "cf-blob")` on the
  conformance socket so the P7 driver can inject `request.cf`; workerd parses
  the header into `request.cf` and strips it before the worker sees it.
- Viceroy's geolocation fixture required **all** `RawGeo` fields (the missing
  `area_code` silently failed the guest-side serde parse → all-None geo).
- Viceroy returns original header names lowercased (hyper's `HeaderMap`); the
  conformance driver asserts presence/order, not case (real Fastly preserves
  spelling — verified source contract, not live).
- TLS metadata is absent under both simulators (Viceroy ABI returns
  absent-metadata; workerd cf-blob has no ja3/ja4 in the public API).
